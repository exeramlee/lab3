# Гарантія — менеджер гарантій і покупок

Кросплатформний застосунок на Flutter для обліку покупок, гарантійних строків і чеків.
Лабораторні роботи з дисципліни «Кросплатформне програмування», НУ «Львівська політехніка».

## ЛР № 3 — базова структура та основні екрани

Екрани реалізовано за макетами без бізнес-логіки (дані — hardcoded у `MockData`):

- вхід, реєстрація, відновлення пароля;
- головний екран із нижньою навігацією;
- профіль і зміна пароля;
- список покупок (пошук, фільтри), гарантії, деталі покупки, форма покупки.

## Структура

```
lib/
├── core/
│   ├── data/      # hardcoded-дані
│   ├── models/    # моделі
│   ├── theme/     # кольори, відступи, ThemeData
│   └── widgets/   # повторно використовувані віджети
└── features/      # екрани за функціями (auth, home, main, profile, purchases, warranties)
```

## Запуск

```bash
flutter pub get
flutter run
```
